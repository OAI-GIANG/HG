# ADR-007 — Bounded Autonomous Execution
Status: Accepted as V1 policy model.
Decision: autonomous actions are allowed only within explicit action/resource/scope authority; re-check authority before each side effect. Read, write, commit, push, merge, deploy, migration and delete are distinct.
Required controls: task envelope, exact authorization, proportionate risk/recovery plan, candidate-bound evidence, mandatory gates and stop conditions. No agent can self-relax a gate to accept its own candidate.
This ADR does not itself grant actual GitHub or runtime permissions; those remain determined by environment and explicit authorization.
