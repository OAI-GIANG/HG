## Acceptance decision
MAEP V1 foundation package passes its local design, schema, and unit-test criteria, and its runtime path (RT-01..RT-07 plus MIID Phase D) is INTEGRATION_TESTED in-process with the trust anchor read live from `main`. It is not a production-certified release and no production deployment exists. Do not label the whole HG system CLOSED_VERIFIED. AC-13 passes at foundation scope with the stated tamper-resistance limitation; AC-14 is intentionally not performed or claimed; AC-17 and AC-26 are enforced in-process only, so same-UID code is not contained. The earlier "AC-12 deferred" and "RT-06 BLOCKED" statements were superseded on 2026-10-28 by the code and tests named above (see `STATUS_RECONCILIATION_20261028.md`).
