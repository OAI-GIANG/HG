# ADR-006 — Contract Schema and Validator
Status: Accepted for V1, with explicit limitation.
Decision: Publish JSON Schema Draft 2020-12 contracts; implement governance invariants in Python standard library. Do not claim this implementation is a complete JSON Schema validator.
Rationale: offline-first and Termux compatibility without mandatory paid services.
Consequence: dialect conformance remains NOT_RUN until a standards-complete validator is run. Runtime checks must stay aligned through conformance tests and traceability.
