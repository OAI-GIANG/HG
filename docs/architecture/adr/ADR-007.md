# ADR-007 — Acceptance and Closure Require Evidence

- Status: Proposed
- Context: Successful execution does not prove that requested outcomes or mandatory controls were satisfied.
- Decision: Separate execution status, verification result, acceptance and closure. CLOSED_VERIFIED requires every mandatory criterion/gate to PASS with evidence bound to the candidate/scope.
- Alternatives: Close on tool success; infer acceptance from lack of errors; accept missing evidence.
- Consequences: Honest state reporting and auditable closure; some tasks remain blocked until evidence is available.
- Rules: MAEP-008, 010, 011, 013, 024, 026.
- Acceptance evidence: Missing/failed gate and evidence tests; NOT_RUN never becomes PASS. Not yet implemented end-to-end.
