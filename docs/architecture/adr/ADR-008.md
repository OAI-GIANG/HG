# ADR-008 — Offline-First Standard-Library Core

- Status: Proposed
- Context: HG targets self-contained operation and should not require paid APIs or a network for core governance.
- Decision: Keep core contracts, state transitions, authorization checks and local evidence handling usable offline; prefer Python standard library. Optional integrations must be isolated adapters and documented.
- Alternatives: Mandatory hosted service; paid API in core path; broad mandatory dependency set.
- Consequences: Lower dependency and operating cost; optional remote capabilities may be unavailable offline and must report that explicitly.
- Rules: MAEP-005, 016, 022, 023.
- Acceptance evidence: Offline test environment runs core conformance suite without network or paid service. Not yet run for architecture.
