# ADR-003 — Versioned Branch Contracts and Minimal Envelopes

- Status: Proposed
- Context: Direct imports of private branch modules create cycles, hidden coupling and excessive authority.
- Decision: Cross-branch communication uses versioned request/result contracts, stable IDs and references. Pass only minimum required data and permissions.
- Alternatives: Shared mutable objects; direct private-module calls; untyped messages.
- Consequences: Requires schema and compatibility tests but improves isolation, observability and future migration.
- Rules: MAEP-001, 004, 010, 011, 028.
- Acceptance evidence: Contract validation and compatibility tests; dependency graph has no branch-to-branch private imports. Not yet implemented.
