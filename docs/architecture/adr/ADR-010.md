# ADR-010 — Evidence-Honest Verification and Review Labels

- Status: Proposed
- Context: Unit tests, internal critique and design inspection can be overstated as runtime verification or independent review.
- Decision: Report evidence level precisely. Do not label internal critique as independent review, do not call unrun tests PASS, and disclose limits of the local ledger.
- Alternatives: Use broad PASS labels; infer integration from unit tests; imply independent review without separate evidence.
- Consequences: Reports may remain BLOCKED/NOT_RUN until evidence exists, but status is auditable and accurate.
- Rules: MAEP-009, 015, 021, 024, 025.
- Acceptance evidence: Report-state tests, review-label guard and consistency audit. This architecture has not undergone independent review or certification.
