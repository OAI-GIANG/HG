# ADR-001 — Single BrainOrchestrator

- Status: Proposed
- Context: Multiple dispatchers create conflicting task state, duplicate authorization paths and ambiguous accountability.
- Decision: BrainOrchestrator is the only logical owner of task lifecycle and cross-branch dispatch.
- Alternatives: Each branch orchestrates peers; distributed orchestration; single coordinator with branch-owned internal workers.
- Consequences: One clear audit trail and authority boundary; coordinator availability becomes important, so durable checkpoints and reconciliation are required. Do not collapse all capabilities into one giant module.
- Rules: MAEP-001, 006, 007, 025, 026.
- Acceptance evidence: Runtime integration test proves all dispatch passes through BrainOrchestrator and terminal transitions use MAEP. Not yet implemented.
