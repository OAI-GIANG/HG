# ADR-005 — End-to-End Task and Evidence Binding

- Status: Proposed
- Context: Unlinked evidence and results can be reused for the wrong candidate, scope or policy version.
- Decision: Every task, step, dispatch, result and evidence item carries stable identifiers and exact candidate/scope/policy references where relevant.
- Alternatives: Free-text logs; evidence detached from candidate; implicit context.
- Consequences: Traceability improves; schemas and retention rules must be maintained.
- Rules: MAEP-010, 011, 012, 015, 024, 025.
- Acceptance evidence: Candidate mismatch, stale evidence, amendment history and closure negative tests. Not yet implemented end-to-end.
