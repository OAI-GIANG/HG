# ADR-002 — Five Functional Branches; MAEP Is Cross-Cutting

- Status: Proposed
- Context: HG needs clear capability ownership without turning governance into a competing functional domain.
- Decision: Keep exactly five functional branches: HG Brain; Memory & Knowledge; Creativity & Research; Tools & Automation; Security & Verification. MAEP is the cross-cutting governance layer, not a sixth branch.
- Alternatives: One monolith; separate governance branch; more specialized branches at initial build.
- Consequences: Responsibility boundaries remain visible; shared MAEP interfaces must be consistently enforced.
- Rules: MAEP-006, 017, 022.
- Acceptance evidence: Responsibility inventory has exactly five branches and no duplicate coordinator/policy owner. Design only.
