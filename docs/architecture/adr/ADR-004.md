# ADR-004 — Fail-Closed Authorization at the Action Boundary

- Status: Proposed
- Context: A coordinator-only check can be bypassed by a direct adapter call or become stale before execution.
- Decision: MAEP evaluates each controlled action; the action adapter re-checks the matching decision immediately before the side effect. Missing, malformed, expired, unavailable or mismatched authority denies execution.
- Alternatives: Trust the plan; cache broad permissions; rely on UI/coordinator checks only.
- Consequences: Safer boundaries and clearer evidence; extra checks may add latency and require explicit failure handling.
- Rules: MAEP-003, 004, 005, 017, 019, 023.
- Acceptance evidence: Negative tests for each binding dimension and adapter-level bypass attempts. Not yet implemented.
